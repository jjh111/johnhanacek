§1.1 · The pitch

One spec on Sunday, one signed brief on Monday.

OpenProse is sold to operators who already trust documents. We take the brief you wrote on Sunday night and turn it into a routine that runs against your data, scored against the spec you signed, and signed back with the evidence of what ran. The deliverable is a verified outcome, not a hopeful artifact. Every Monday lands with a paper trail attached.

The product has three pieces. Prose: the spec the operator signs — written in this direction, in this voice. Runtime: the engine that reads the spec and produces the outcome. Receipt: the signed PDF that arrives in your inbox with the spec it ran against, the data it touched, and the score it reached. The style guide builds the first piece. RLM! builds the second. The receipt is the third — half style, half RLM. This companion is about how those three meet on the page.

A brief the model can run, signed by the operator who can read it. OpenProse · the elevator pitch
§2 · Why this direction

Tufte, in mono, with Kecal in the accent seat.

The product is half spec, half essay. The reading face has to honour both. We use IBM Plex Mono for the body because the mono keeps spec and essay visually honest — a column number in a paragraph reads the same as in a code block. Kecal sits in the accent seat because its extrabold static carries the emphasis a synthesised slant would lose. The page sits on warm fog cream over a cocoa brown-black ink — generous, calm, and unafraid of a short sentence.

Three accents do the editorial work. Teal #3a7a6a handles the writer's pivot: the word in Kecal where the sentence turns. Golden amber #c49a5c is the warm complement held for the rare "look up" moment — the proof, the promise, the boundary. Editorial red #c0392b is the fail signal — failed evals, broken contracts, the badge that says this needs you. Never mix red with teal in the same phrase; they're independent registers.

The form fits the function

A spec needs measurement. Tufte's narrow column gives the eye a fixed line length — 62 characters, no more. The five-step ink ramp tells the reader which line is load-bearing without colour. The sidenote (the marginal numbered footnote) is the brand — it lets the writer say "this matters; the body did not need it" without interrupting the column.

§3 · How to use the style

Six recipes for landing a page in this direction.

Each recipe is a one-page pattern with the shape, the tokens, and the voice decided. Drop one into a new file, fill the slots, and you have a page that reads as part of the same document family.

Recipe · I

The hero spec page

A single ledger-page hero: name, tagline, and the load-bearing claim. Teal carries the accent pivot. One bang sidenote on the line you'd shake on. Use for the front of any new direction.

Recipe · II

The contract spread

Two columns: terms on the left in mono small-caps, the prose explanation on the right. Teal underlines the term. Red flags a clause that still needs the operator's signature.

Recipe · III

The runtime brief

A Monday-morning page. Lede paragraph, sidenote-rich body, amber on the one outcome that landed early. Footer carries the spec hash and signature.

Recipe · IV

The evaluation card

A single card per evaluation. Pass-rate in mono; teal hairline; red badge on any failed contract. The card stacks 4-up on the dashboard or sits alone on the page.

Recipe · V

The style demo

A live component. Pretext-grabbable mark with a swatch row below — the same pattern wired in §6.15. Use to show off interaction without a full hero.

Recipe · VI

The voice specimen

One sentence per register: short, spec, editorial. Used in onboarding pages or as a footer on a long document, to remind the writer of the cadence.

§4 · The style + RLM · what each side gains

Style is what the operator reads. RLM is what runs against it.

OpenProse pairs a human surface (this direction) with a machine surface (Reliable Language Modeling). The pairing matters: this style was designed with RLM in the room. The two surfaces gain different things from the pair.

Style · the operator gains

Readability under load. Mono body lets a number-heavy paragraph read as cleanly as a marketing line.

A signature surface. Tufte's column + the Kecal accent feel like a document you'd put your name on — which is exactly what a signed brief should feel like.

A vocabulary for emphasis. Accent / sidenote / bang / amber / red give the writer five ways to say "look here" without resorting to weight or colour competition.

RLM · the runtime gains

A spec the model can parse. Tokenized typography (mono terms, accent pivots, sidenotes) maps cleanly into a structured contract the runtime can verify.

Failure semantics in the design. Red is the colour of a broken contract — the same colour the runtime emits in the receipt. Operator and machine speak the same colour.

An audit trail in the page. Every fragment carries a marginal anchor (sidenote / class hook / spec hash). The runtime can dereference any of them after the fact.

The shared surface — the receipt

Where the two halves meet: the Monday-morning receipt. It is rendered in this direction (paper-cream, mono body, teal pivots) but every fragment maps to an entry the runtime emitted — a verified outcome, a passed eval, a failed contract. The receipt is the proof that the brief that ran on Sunday is the brief that arrived on Monday. The style makes it readable; RLM makes it true.

We don't ask the model. We contract the model. OpenProse · the unique value, in eight words

Three values unique to the pair

Value · I

Spec-grade legibility

The page reads the way a good analyst would have written it. The model produces against the same surface, so reviewer and runtime see one document.

Value · II

A shared failure colour

Red on the page is red in the receipt is red in the eval log. A failed contract has one face across all three surfaces.

Value · III

Audit-by-construction

Every sidenote in a brief is an anchor in the verified-outcome graph. The reader can follow any "look up" mark back to the run that produced it.

§5 · Voice playbook

Three registers, one cadence.

The brand voice is calm, specific, and unafraid of a short sentence. The same writer holds all three registers; the difference is the cadence and the punctuation.

Short · declaration · the hero seat
"Write the outcome. We run it."
Six words. The tagline cadence. One verb on each side of the line. Use on hero, elevator, the front of any brief.
Spec · bang · the contract seat
"Billed by delivery!. If the outcome doesn't ship, no line."
Terms of art spoken plainly. The bang on the one word that carries the rule. One bang per page. The brand's rare register.
Editorial · accent · the long-form seat
"Once, the week began with a scramble. Then the outcome was declared in a file."
The narrative register. The accent carries the pivot. Sidenotes optional but welcomed. Use for the lede of a brief and the colophon.
Sidenote skim · dotted · sn marker
The standup happens anyway, but it is fifteen minutes shorter3. Nobody asks where the numbers came from.
When the sidenote can live on the line: a dotted hairline under the clause + a numeric <sup class="sn">n</sup>. The "skim" register — many per page is fine.
Sidenote hot · dashed · sn ! marker
"Billed by delivery!. If the outcome doesn't ship, no line."
The page's single load-bearing claim. Dashed hairline + a bang sidenote. One per page; if you reach for a second, the first is wrong.

The three rules of register

One: the accent is the writer; the sidenote is the reader. Two: accent and sidenote never share a phrase. Three: one bang per page — if you reach for a second, the first is wrong. Tufte respected the eye; we respect the operator.

§6 · Anti-patterns

The mistakes that read as wrong.

Five patterns that go wrong most often when a new operator picks up the direction. Each is paired with the corrected version.

Don't · loud emphasis

EVERY OUTCOME IS SIGNED AND VERIFIED. NO EXCEPTIONS.

Do · accent pivot

Every outcome is signed and verified. No exceptions.

Don't · mixed red + teal

An accent in red sits in a paragraph that already has a teal pivot.

Do · one register per phrase

A failed clause stands alone in a row with a red badge. The body sentence holds its teal pivot elsewhere.

Don't · two bangs

Billed by delivery!. Hold! a brief that misses contract.

Do · one bang, the one that matters

Billed by delivery!. Hold a brief that misses contract.

Don't · amber as decoration

Three amber phrases in the same paragraph turn the page into a holiday card.

Do · amber on the load-bearing claim only

The brief is signed. Seven years, by default. The clause is the page.

Don't · pure black

Body type set in pure #000 over warm cream — reads as plastic, breaks the temperature of the page.

Do · warm cocoa ink

Body type set in #2a2520 — the ink stays warm against the cream, the eye stays calm.

§7 · Picking up the style cold

The minimum to ship a new page in this direction.

An agent or a teammate landing on the project fresh should be able to produce a publishable page in this direction without re-deriving the system. The list below is the shortest ramp. 

# Pick up cold — seven moves.

1. Read the parent style guide end-to-end (one pass) # direction-beta-tufte-mono-kecal-styleguide-teal.html
2. Copy the :root token block from §0.2 verbatim into your new file
3. Wire the seven-weight Kecal @font-face block + IBM Plex Mono @import
4. Set body to var(--mono) at 1.08rem / 1.7 line-height
5. Wrap every emphasis in <em>; the global rule renders it in teal italic
6. Reach for <sup class="sn"> before .hl — the sidenote is the brand
7. Tag every override // JH YYYY-MM-DD with the verbatim review quote

# If any rule conflicts with a user instruction, ask before deviating.
# See §6 anti-patterns for the five mistakes the system catches early.

Two questions to ask before you ship

  1. Is there one bang on the page? If yes, is it on the right phrase? If two, the first one is wrong.
  2. Is amber load-bearing? If amber lands on something the reader could skip, the page is using it as decoration. Move it or drop it.

Both files — this companion and its parent guide — are versioned together. If the direction shifts, update them in lockstep. Tag the change with the verbatim review quote. The guide is the contract; this companion is the rehearsal.
