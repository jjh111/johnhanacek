How it works

From intent to outcome in three moves.

Declare the outcome.

Write a .prose file. requires: for inputs, ensures: for what must be true after a run. Plain language. Fifteen lines. Version-controlled.

The runtime verifies.

Each draft is scored against the contract. Below threshold, the runtime holds and pages on-call. No silent failures. No shipping bad work.

The result arrives.

Pass once, deliver. Sign the result. Every Monday at 09:00 ET — Slack, email, webhook. Bill only on a delivered, verified outcome.

The whole program is fifteen lines.

weekly-energy-digest.prose is a real responsibility running at Ridgeline Properties. It ships every Monday at 09:00, covers forty buildings, and has run for forty-two weeks without manual intervention.

The file fits on one screen. The runtime does the rest.
