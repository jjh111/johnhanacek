0x01 · Palette

Cocoa, ink, amber. That's it.

Two surfaces and one keyword color. The page is cocoa #0e0e10 — not pure black, never pure black, because pure black on a CRT or modern OLED is hostile. Ink is a slightly desaturated cream #e8e4dc that reads at terminal contrast without burning. Amber #d4a64f handles every keyword, every accent, every link — the same color a syntax highlighter uses for "constant". A second color, warn-red #d4604f, is held back for the single hot mark that means "this is the line that fails closed".

0x02 · Type Scale

One face. IBM Plex Mono. Everywhere.

No proportional type appears anywhere on the page. IBM Plex Mono carries display, body, UI, and code at five weights. Italic exists, but it is reserved for the keyword — the word the sentence turns on — and it is always rendered upright with amber color, because a slanted glyph in a monospace grid breaks the grid. The brand voice is the terminal's voice: every glyph occupies the same cell, every line aligns to the same column.

0x04 · UI Elements

Buttons, badges, and a specification.

Interface primitives are typed commands. Buttons take a $ sigil. Badges take a ! for live and 0 for verified. There is no uppercase chrome — the type stays cased the way a programmer would type it. The code surface is the same surface as everything else: this is the only direction where prose and code share a face.

0x05 · The Keyword

The em is amber. The hot is warn-red.

δ's emphasis is the syntax highlight. Where α used italic-red, δ uses an upright amber word with a faint amber background — the same gesture an editor renders for a language keyword. Where α's "hot" was a warm-red highlighter, δ's hot is a desaturated red on a small slab background — the visual language of a compiler warning. The two are stylistically of a piece: this whole brand thinks like a syntax tree.

// keyword
Every Monday at 09:00 ET, the digest arrives — verified, signed, archived. The standup happens anyway, but it is fifteen minutes shorter.
// warn
Billed by delivery. If the outcome doesn't ship, no line.
// keyword + em
The humanist computer is the insight that these two dispositions — craft and machinery — are not opposed. The machine handles the cadence. The prose handles the voice.
Rule · keyword Use on the nouns and numbers a programmer would copy out of the prose if they were taking notes. Never on verbs, always on what the sentence is naming.
Rule · warn Use on the single fail-closed claim per page — the proof, the promise, the boundary. Two warns on one page desensitizes the warning.
Rule · layering Em (italic, upright amber) and keyword (amber slab) never share a phrase. The writer's emphasis and the syntax tree's emphasis stay on separate layers.
Rule · the mark Never on the logotype. Never on a button. The keyword highlight is a prose tool only — body copy, h2/h3, document body. Buttons get the $ sigil; badges get ! or 0; the brand mark gets nothing.
0x06 · Editorial Pairing

Set in mono — the voice at length, with syntax.

The machine voice is calm, specific, and unafraid of a short sentence. It names things by their nouns. It reaches for the keyword highlight only when a programmer would copy that word into a note. The whole thing reads as if a careful operator wrote it in their own editor.

From the field notes

On the quiet arrival of Monday reports.

Once, the week began with a scramble. Someone opened seven dashboards, pulled the numbers, wrote the digest, and dropped it in the 09:00 standup. The rotation was a line in the budget. The standup was a line in the calendar. Nobody was quite sure what either accomplished beyond confirming that the dashboards were fine.

Then the outcome was declared in a file. Fifteen lines. Every Monday at 09:00 ET, the digest arrives — verified, signed, archived. The standup happens anyway, but it is fifteen minutes shorter. Nobody asks where the numbers came from. They are already in the document.

The first thing we noticed was what we stopped doing — the standing meetings where we'd review the dashboard to confirm the dashboard was fine.

The humanist computer is the insight that these two dispositions — craft and machinery — are not opposed. The machine handles the cadence. The prose handles the voice. The page reads the way a good analyst would have written it. The result is the point.

0x08 · Voice & Tone

Three sentences, one register, three syntax modes.

Three sanctioned voices the brand uses: the short declaration, the spec-sheet note, the editorial observation. Each sentence can live on its own without ornament — and each demonstrates one mode of the syntax highlighter.

Voice · short · keyword
“Write the outcome. We run it.”

The tagline. Six words. The keyword lands on the second sentence — the part that shifts the burden from the operator to the runtime.

Voice · spec · warn
“Billed by delivery. If the outcome doesn't ship, no line.”

Terms of art spoken plainly. Warn-red on the one word that defines the pricing model — the boundary a reader cannot skim past.

Voice · editorial · em
“Once, the week began with a scramble. Then the outcome was declared in a file.”

The long form voice. The em (upright amber) carries the pivot. No keyword highlight here — this sentence is still the author's, not the syntax tree's.
